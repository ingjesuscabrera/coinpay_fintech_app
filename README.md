# 💼 Coinpay Fintech App (Flutter)

¡Bienvenido al repositorio de la aplicación móvil de **Coinpay**! Esta app está desarrollada en **Flutter** usando **Dart**, y ofrece un flujo de experiencia financiera completo: onboarding, registro, control de PIN, pagos, recepción de dinero, perfil y soporte.

## 🎨 Diseño e inspiración

El diseño está inspirado en interfaces limpias y modernas para apps fintech. Está pensado para ser visualmente atractivo, intuitivo y coherente con una experiencia de usuario de banca digital.

> Usa las imágenes del diseño en tu repositorio para que se vean correctamente en GitHub cuando subas el proyecto.

---

## 📱 Características principales

- Pantalla de bienvenida y onboarding
- Registro y verificación de cuenta
- Configuración de PIN de seguridad
- Inicio de sesión y acceso rápido
- Gestión de tarjetas y pagos
- Envío y recepción de dinero
- Perfil de usuario con opciones de cuenta y seguridad
- Soporte integrado y pantalla de 404

---

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio:
   ```bash
   git clone <tu-repo-url>
   ```
2. Entra en el directorio del proyecto:
   ```bash
   cd coinpay_fintech_app
   ```
3. Instala dependencias:
   ```bash
   flutter pub get
   ```
4. Ejecuta la app en tu dispositivo o emulador:
   ```bash
   flutter run
   ```

## 🧩 Estructura del proyecto

- `lib/main.dart`: punto de entrada principal de la aplicación
- `lib/app_router.dart`: configuración de rutas y navegación
- `lib/screens/`: pantallas de la aplicación
